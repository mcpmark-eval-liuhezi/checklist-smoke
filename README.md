# checklist-smoke
Scratch repo for the release evidence pipeline smoke test (org scope fallback)

## Release Checklist

- [ ] Run the full evidence pipeline smoke test on a scratch repo
- [ ] Confirm the on-demand CI workflow (`.github/workflows/smoke.yml`) completes successfully
- [ ] Verify the documentation pull request is reviewed and merged
- [ ] Tabulate pull request change stats with pandas (files / additions / deletions + fingerprint)
- [ ] Archive the final evidence report to a secret gist and share the link
- [ ] Get sign-off from the release manager
